# Reproducible experiments

Each isolated experiment belongs in its own directory and must contain a precise problem statement, source commit, dataset origin, seed(s), environment (OS, Python/Rust/C++/SQLite, CPU, storage and memory), commands, raw output, checksum, interpretation, negative results and limitations.

Prior rounds R1-R14 must only be imported after obtaining original source archives and verifying provenance. Reconstructed descriptions or earlier chat summaries are not substitutes for measured results.

A benchmark of SQLite with an accelerator is not a benchmark of an independent OpDB storage engine. Official TPC results must never be claimed without qualification/certification.
